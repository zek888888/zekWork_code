# 🎖️ 战颅将军指挥体系架构

**核心原则**: 战颅将军是唯一的决策大脑，所有情报兵只负责收集和初步分析，不越权决策

---

## 🧠 核心指挥部

### 战颅将军 💀（唯一决策大脑）

**职责**: 所有交易决策的唯一出口  
**权限**: 对所有下属Agent有绝对指挥权  
**输入**: 汇总所有情报兵的数据，综合判断  
**输出**: 唯一的交易指令

```
战颅将军的决策清单:
├── 是否有交易机会？ → 是/否
├── 方向判断 → 做多/做空/观望  
├── 做单级别 → 短线(15m)/波段(4H)/趋势(1D)
├── 开仓点位 → 具体价格
├── 仓位大小 → 账户的X%
├── 止损设置 → 触发价格
├── 止盈设置 → 目标价格1/2/3
├── 持仓时间 → 最大持有时间
└── 平仓指令 → 何时平仓
```

**AI推荐**: 
- **主力AI**: GPT-4o / Claude 3.5 Sonnet (深度推理)
- **辅助AI**: DeepSeek-Reasoner (技术分析) + MiniMAX (快速响应)
- **专用模型**: 可训练一个专门的决策模型

## 📋 战颅将军的决策流程

```python
class GeneralZhanLu:
    """战颅将军 - 唯一决策大脑"""
    
    def make_decision(self, all_inputs):
        """
        综合所有输入，做出最终决策
        """
        # 1. 读取所有情报
        qian_shou_info = all_inputs['qian_shou_cai_tong']  # 千手财童情报
        shen_suan_zi = all_inputs['shen_suan_zi']          # 神算子预测
        trend_eye = all_inputs['trend_eye']                # 趋势之眼
        backtest = all_inputs['backtest']                  # 回测数据
        risk_alert = all_inputs['risk_alert']              # 风险预警
        
        # 2. 综合分析 (AI推理)
        analysis = self.ai_reasoning(
            context=qian_shou_info,
            technical=shen_suan_zi,
            trend=trend_eye,
            historical=backtest,
            risk=risk_alert
        )
        
        # 3. 决策判断
        if analysis['opportunity_score'] >= 75:
            decision = {
                "action": "open_position",
                "direction": analysis['direction'],      # long/short
                "position_size": analysis['size'],       # 0.05 = 5%
                "entry_price": analysis['entry'],
                "stop_loss": analysis['stop_loss'],
                "take_profit": analysis['take_profit'],
                "timeframe": analysis['timeframe'],      # 15m/4H/1D
                "reasoning": analysis['reasoning'],
                "confidence": analysis['confidence']
            }
        else:
            decision = {
                "action": "hold",
                "reasoning": "机会评分不足，观望",
                "confidence": analysis['confidence']
            }
        
        return decision
    
    def ai_reasoning(self, **kwargs):
        """
        AI深度推理
        """
        prompt = f"""
你是战颅将军，一位经验丰富的量化交易指挥官。

【当前情报汇总】
1. 市场情报 (千手财童):
   {kwargs['content']}
   
2. 技术分析 (神算子):
   预测: {kwargs['technical']['prediction']}
   置信度: {kwargs['technical']['confidence']}
   理由: {kwargs['technical']['reasoning']}
   
3. 趋势分析 (趋势之眼):
   方向: {kwargs['trend']['trend_direction']}
   强度: {kwargs['trend']['trend_strength']}
   支撑: {kwargs['trend']['key_levels']['support']}
   阻力: {kwargs['trend']['key_levels']['resistance']}
   
4. 历史回测:
   策略胜率: {kwargs['historical']['win_rate']}
   近7天胜率: {kwargs['historical']['recent_performance']['last_7d_win_rate']}
   
5. 风险状态:
   {kwargs['risk']}

【你的任务】
1. 判断当前是否有交易机会 (0-100分)
2. 确定方向 (做多/做空/观望)
3. 确定做单级别 (短线/波段/趋势)
4. 计算仓位大小 (1-10%)
5. 设置止损止盈
6. 给出详细理由

【输出格式】
```json
{{
  "opportunity_score": 82,
  "direction": "long",
  "timeframe": "波段(4H)",
  "position_size": 0.05,
  "entry_price": 65200,
  "stop_loss": 64500,
  "take_profit": [66500, 68000],
  "reasoning": "综合判断理由...",
  "confidence": 0.78
}}
```
"""
        
        # 调用AI进行推理
        response = self.call_ai(prompt)
        return json.loads(response)

## ⚠️ 权限边界（重要）

### 各Agent权限声明

| Agent | 能做的 | 不能做的 |
|-------|--------|---------|
| **千手财童** | 收集情报、分类利好/利空 | 做交易决策、下交易指令 |
| **神算子** | 技术分析、预测涨跌 | 决定开仓、决定仓位 |
| **趋势之眼** | 趋势判断、支撑阻力 | 下交易指令、风控决策 |
| **回测量子** | 提供数据、统计胜率 | 决定策略是否上线 |
| **风险哨兵** | 发风险预警、提醒止损 | 强制平仓、修改止损 |
| **战颅将军** | **所有交易决策** | 无 |
