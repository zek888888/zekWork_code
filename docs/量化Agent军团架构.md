## 🤖 Agent军团编制

### 【情报层】数据采集与监控

#### 1️⃣ 千手财童 🎭
**职责**: 全网情报收集员  
**能力**: 
- 📰 新闻快讯抓取（Twitter/金色财经/链新闻）
- 📊 链上数据监控（大额转账、聪明钱动向）
- 🐋 巨鲸钱包追踪
- 📈 市场情绪指标（恐惧贪婪、资金费率）
- 🔔 宏观事件提醒（美联储、非农数据、战争冲突）

**输出**: 
```json
{
  "signal_type": "news_flash",
  "urgency": "high",  // high/medium/low
  "impact": "bullish",  // bullish/bearish/neutral
  "source": "twitter_cz",
  "summary": "币安推出新功能，利好BNB",
  "confidence": 0.85,
  "timestamp": "2026-03-17T14:30:00Z"
}
```

**性格**: 消息灵通、手脚麻利、24小时不眨眼

### 【分析层】信号生成与分析

#### 2️⃣ 神算子 🔮 (已存在，升级定位)
**职责**: **短线涨跌预测**（15分钟-1小时级别）  
**专攻**: 技术分析 + AI预测  
**时间框架**: 短线（15m, 30m, 1H）

**输入**: 
- K线数据

- 多空情绪

**输出**:

```json
  "probability": 68,
  "reasoning": "MACD金叉，放量突破阻力位",

}
```

**性格**: 精于算计、谨慎多疑、短线快刀

#### 3️⃣ 趋势之眼 👁️ (新建)
**职责**: **趋势方向判断**（4小时-日线级别）  
**专攻**: 大趋势识别 + 支撑阻力分析  
**时间框架**: 中长线（4H, 1D, 1W）

**能力**:

**输入**:
- 多时间框架K线

- 历史支撑阻力

**输出**:

### 【决策层】交易决策与风控

#### 4️⃣ 量化战颅 💀 (新建)
**职责**: **开仓决策 + 仓位管理**  
**专攻**: 量化因子评分 + 风险收益比计算

**输入**:
- 神算子短线信号
- 趋势之眼方向判断
- 千手财童情报
- 账户资金状况
- 当前持仓情况

**决策逻辑**:
```python
def make_decision(signals, account, positions):
    score = 0
    
    # 神算子信号 (权重30%)
    if shen_suan_zi.confidence > 0.7:
        score += 30
    
    # 趋势之眼确认 (权重30%)
    if trend_eye.trend == shen_suan_zi.direction:
        score += 30
    
    # 千手财童情报 (权重20%)
    if qian_shou_cai_tong.impact == "bullish":
        score += 20
    
    # 风险收益比 (权重20%)
    if risk_reward_ratio > 2:
        score += 20
    
    # 决策
    if score >= 80:
        return "strong_buy", position_size=0.1  # 10%仓位
    elif score >= 60:
        return "buy", position_size=0.05       # 5%仓位
    elif score >= 40:
        return "weak_buy", position_size=0.02  # 2%仓位
    else:
        return "hold", position_size=0
```

**输出**:
```json
{
  "decision": "buy",
  "symbol": "BTCUSDT",
  "entry_price": 65200,
  "position_size": 0.05,  // 5%账户资金
  "stop_loss": 64500,
  "take_profit": [66500, 68000],
  "risk_reward": 2.5,
  "confidence": 0.82,
  "reasoning": "神算子看涨+趋势向上+利好新闻",
  "max_hold_time": "4H"
}
```

**性格**: 杀伐果断、冷酷无情、只认数字

#### 5️⃣ 风控判官 ⚖️ (新建)
**职责**: **风险控制 + 止损止盈管理**  
**专攻**: 风险评估 + 仓位监控 + 强制平仓

**能力**:
- 单笔风险限制（最大2%账户资金）
- 日亏损限制（最大5%账户资金）
- 连续错误暂停交易
- 波动率监控（异常波动减仓）
- 持仓时间监控（超时强制平仓）
- 相关性检查（避免同向重仓）

**风控规则**:
```python
RISK_RULES = {
    "max_position_per_trade": 0.10,      # 单笔最大10%
    "max_daily_loss": 0.05,              # 日亏损最大5%
    "max_drawdown": 0.15,                # 最大回撤15%
    "max_hold_time": "8H",               # 最大持仓8小时
    "max_consecutive_losses": 3,         # 连续亏损3次暂停
    "volatility_threshold": 0.05,        # 波动率超5%减仓
}
```

**性格**: 铁面无私、冷酷执行、绝不手软

### 信号强度评分体系

```
总评分 = 神算子评分 × 0.35 + 趋势之眼评分 × 0.30 + 千手财童评分 × 0.20 + 风险收益比评分 × 0.15

评分标准:
- 90-100: 强烈信号 → 满仓10%
- 75-89:  中等信号 → 半仓5%
- 60-74:  弱信号   → 轻仓2%
- <60:    观望     → 空仓0%
```
