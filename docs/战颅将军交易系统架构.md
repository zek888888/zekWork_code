## 核心参数

### 资金配置
- **启动资金**: 10000 USDT
- **最小交易单位**: 5分钟级别
- **杠杆范围**: 1-10x 可调
- **最大回撤限制**: 20%（2000U）

### 数据周期
- **交易周期**: 5分钟（最小开仓单位）
- **分析周期**: 5m, 15m, 30m, 1H, 2H, 4H, 12H, 1D, 1W, 1M, 1Q
- **历史数据**: 2021-01-01 至今

### 技术指标
- MACD (多周期)
- KDJ (多周期)
- 布林带 (多周期)
- RSI (多周期)
- EMA均线系统 (9/21/55/89)
- ATR波动率
- 成交量分析

## 交易规则

### 开仓条件
1. 战颅将军综合评分 >= 70分
2. 多周期共振（至少3个周期同向）
3. 风险收益比 >= 2:1
4. 仓位不超过总资金20%
5. 必须设置止损

### 平仓条件
1. 止盈触发（分批止盈）
2. 止损触发
3. 持仓超时（最大8小时）
4. 战颅将军发出反向信号
5. 黑天鹅事件（波动率>5%）

### 杠杆管理
- 高置信度(>80%) + 趋势明确: 5-10x
- 中等置信度(60-80%): 3-5x
- 低置信度(<60%): 1-2x 或不开仓

## 数据流

```
Binance API → 千手财童 → 技术指标计算 → 多周期数据整合
                                                    ↓
Web展示 ← 交易记录 ← 模拟盘引擎 ← 战颅将军决策 ← 亲兵小队分析
```

```

│         战颅将军交易系统                 │
```
