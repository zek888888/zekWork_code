## 🎯 最终推荐组合

### 主推：方案A（冷酷军事风）

```
战颅将军 💀 (主将)
    │
    ├─ 影谍 👁️ (情报分析)
    ├─ 铁算 ⚙️ (风险评估)
    ├─ 史官 📜 (策略回测)
    ├─ 谋师 🧠 (决策生成)
    └─ 宪兵 ⚖️ (执行检查)
```

**呼号示例**:
- 战颅将军: "影谍，报告敌情！"
- 影谍: "报告将军，多方情报汇总完毕，市场情绪偏多..."
- 战颅将军: "铁算，评估风险！"
- 铁算: "报告将军，风险等级中等，建议仓位5%..."
- 战颅将军: "史官，验证策略！"
- 史官: "报告将军，该策略历史胜率68%，近7天胜率75%..."
- 战颅将军: "谋师，制定方案！"
- 谋师: "建议做多，入场价65200，止损64500..."
- 战颅将军: "宪兵，审核！"
- 宪兵: "审核通过，符合风控规则，可以执行！"
- 战颅将军: "命令下达，执行交易！"
