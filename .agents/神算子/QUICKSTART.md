# 🚀 Agent快速上手指南

## 一分钟上手

### 1️⃣ 启动Agent执行预测

```python
# 告诉AI助手（我）：
"帮我执行一次BTC预测"

# 我会自动执行：
from prediction_agent import PredictionAgent
agent = PredictionAgent()
result = agent.predict(symbol='BTCUSDT', interval='15m')

# 然后展示结果给你
```

### 2️⃣ 查看预测结果

```bash
# 访问Web页面
http://localhost:5000/trading_signals

# 或者问我：
"显示最近的预测统计"
```

### 3️⃣ 让Agent学习优化

```bash
# 告诉我：
"让Agent学习一下最近的预测"

# 我会执行：
agent.learn(force=True)
```

## 🎯 三种使用模式

### 模式A：全自动（推荐）

```bash
# Agent自动运行，你只需定期查看报告
# Cron定时执行，无需人工干预

查看方式：
1. 访问 /trading_signals 页面
2. 或问："最近预测怎么样"
```

### 模式B：半自动

```bash
# Agent自动预测，但重大决策需确认
# 比如：Prompt优化、策略调整

示例：
Agent: "建议修改Prompt，是否执行？"
你： "问问AI助手这个建议怎么样"
我： 分析建议 → 给出意见 → 协助执行
```

### 模式C：手动控制

```bash
# 完全由你控制何时预测
# 适合测试和调试

操作：
"执行预测" → 我立即运行Agent
"验证结果" → 我对比实际价格
"分析失败" → 我深度分析原因
```
