```

│                                                                                 │

│  │   数据获取   │  │   预测引擎   │  │   验证器    │  │  学习器   │  │
│  │   (Fetcher)  │  │  (Predictor) │  │(Validator) │  │ (Learner) │  │
```

## 核心特性

### 1. 🤖 自主学习能力

Agent能够自动分析历史预测结果，识别成功/失败模式，不断优化预测策略。

### 2. 📚 知识库系统

积累预测经验，形成可复用的知识资产。

### 3. 🔄 实时反馈循环

```
预测 → 等待结果 → 验证 → 分析 → 学习 → 优化 → 应用下次预测
```

## 快速开始

```python
from prediction_agent import PredictionAgent

agent = PredictionAgent()

# 执行预测
result = agent.predict(symbol='BTCUSDT', interval='15m')

# 验证待处理的预测
agent.verify_pending()

# 运行学习循环
agent.learn()
```
