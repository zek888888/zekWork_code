# 🤖 Agent指挥AI助手工作流程

## 概述

本文档定义预测Agent如何指挥AI助手（我）完成预测任务，以及我们之间的协作流程。

```
用户指令 → Agent调度 → AI助手执行 → 结果返回 → Agent学习
```

## 🎯 具体使用场景

### 场景1：定时自动预测（无需人工干预）

```bash
# 由Cron定时触发，完全自动化
cron: 每15分钟执行一次

流程：
1. Agent获取最新K线数据
2. Agent调用AI(DeepSeek+Kimi)进行预测
3. Agent保存预测结果到数据库
4. 等待下一个周期...
```

**我的角色**：无需参与，系统自治

---

### 场景2：预测异常，需要我协助

```python

    result = agent.predict()

    agent.request_assistance(
        task="debug_prediction",
        error=str(e),
        context={...}
    )
```

**用户操作**：
```bash
# 用户告诉我：
"Agent预测失败了，帮我看看"

# 我会：
1. 查看错误日志
2. 分析问题原因
3. 提供解决方案
4. 协助修复
```

**我的角色**：故障排查和修复

## 🎮 实战示例

### 示例1：完整预测流程

```bash
# 用户指令：
"执行预测并告诉我结果"

# 我的操作：

# 1. 调用Agent
from prediction_agent import PredictionAgent
agent = PredictionAgent()

# 2. 执行预测
result = agent.predict(symbol='BTCUSDT', interval='15m')

# 3. 格式化输出给用户
print(f"""
📊 预测结果
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⏰ 预测时间：{result.initiated_at}
🎯 目标时段：{result.target_period[0]} - {result.target_period[1]}
📈 预测方向：{result.consensus_prediction.upper()}
📊 涨概率：{result.consensus_up_probability}%
📉 跌概率：{result.consensus_down_probability}%
💪 置信度：{result.consensus_confidence*100:.0f}%
🤖 参与AI：{len(result.ai_predictions)}个

各AI预测详情：
{chr(10).join(f"  • {ai['ai_name']}: {'📈' if ai['prediction']=='up' else '📉'} {ai['up_probability']}%涨 (置信度{ai['confidence']*100:.0f}%)" for ai in result.ai_predictions)}
""")
```

### 示例2：分析预测准确率

```bash
# 用户指令：
"分析一下最近7天的预测准确率"

# 我的操作：

# 1. 获取性能报告
report = agent.get_performance_report(days=7)

# 2. 深度分析
if report['overall']['total'] > 0:
    accuracy = report['overall']['correct'] / report['overall']['total'] * 100
    
    print(f"""
📈 预测准确率分析（最近7天）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总预测次数：{report['overall']['total']}
正确次数：{report['overall']['correct']}
准确率：{accuracy:.1f}%
平均置信度：{report['overall']['avg_confidence']*100:.0f}%

AI表现排名：
{chr(10).join(f"  {i+1}. {ai['ai_name']}: {ai['correct']}/{ai['total']} ({ai['correct']/ai['total']*100:.1f}%)" for i, ai in enumerate(sorted(report['ai_performance'], key=lambda x: x['correct']/x['total'] if x['total']>0 else 0, reverse=True)))}
""")
    
    # 3. 给出建议
    if accuracy < 60:
        print("\n⚠️ 建议：准确率偏低，建议执行学习优化")
        print("执行：agent.learn(force=True)")
```

## 🔔 通知机制

### Agent何时通知我

| 场景 | 通知方式 | 紧急程度 |
|------|---------|---------|
| 预测执行失败 | 日志+Web提示 | 高 |
| 准确率低于阈值 | 每日报告 | 中 |
| 发现新的失败模式 | 学习报告 | 中 |
| 知识库需要更新 | 建议提示 | 低 |
| 系统异常 | 实时告警 | 高 |

### 我如何响应

```
收到通知 → 分析问题 → 提供方案 → 实施修复 → 验证结果 → 反馈用户
```

## 📞 紧急情况处理

### Level 1: 预测完全失败

```
症状：连续多次预测失败
处理：
  1. 检查AI API状态
  2. 检查数据库连接
  3. 检查数据新鲜度
  4. 修复后手动触发测试
```

### Level 2: 准确率骤降

```
症状：准确率从70%降到50%以下
处理：
  1. 分析失败案例
  2. 检查市场环境变化
  3. 调整预测策略
  4. 增加学习频率
```

### Level 3: 系统异常

```
症状：Agent无法启动或崩溃
处理：
  1. 查看错误日志
  2. 检查依赖项
  3. 修复代码问题
  4. 重启服务
```

## 💡 最佳实践

1. **信任但验证**：Agent自动运行，但定期检查结果
2. **渐进优化**：不要一次性修改太多，逐步调整
3. **记录变更**：每次优化都要记录，便于回滚
4. **监控告警**：设置关键指标告警
5. **人机协作**：复杂决策交给AI助手（我）
