## [3.2.0] - 2025-03-12

### 🎯 市场信息总览页面

#### 新增

- **市场信息总览页面** (`/market_overview`)
  - 新闻聚焦：展示最新市场新闻数据，包含情绪分析
  - 虚拟货币大盘：BTC/USDT 15分钟K线图，支持MACD指标
  - 板块追踪：展示科技、金融、新能源等板块龙头股
  - 热点土狗：集成GMGN热门币种前10名
  - 聪明钱包持仓：支持添加钱包地址追踪持仓

- **新增API接口**
  - `/api/news/latest` - 获取最新新闻
  - `/api/crypto/btc` - 获取BTC K线数据
  - `/api/gmgn/hot` - 获取GMGN热门币种
  - `/api/smart_wallet/list` - 获取追踪的钱包列表
  - `/api/smart_wallet/add` - 添加聪明钱包
  - `/api/smart_wallet/remove` - 移除聪明钱包

#### 变更

- 原"仪表板"页面重命名为"市场信息总览"
- 导航栏更新为新的页面名称
- 页面布局改为三栏响应式设计

## [3.1.0] - 2025-03-12

### ✨ 组件完善 - 新增4个核心组件

#### 新增

- **Dialog 模态对话框组件**
  - 支持遮罩层、动画过渡效果
  - 提供 alert、confirm、prompt 三种预设模式
  - 支持 ESC 键关闭、点击遮罩关闭
  - 可自定义宽度和样式

- **Dropdown 下拉菜单组件**
  - 支持点击/悬停触发
  - 键盘导航（上下箭头、Enter、Esc）
  - 自动定位调整（避免超出视口）
  - 支持分组、分割线、快捷键显示

- **Tabs 标签页组件**
  - 支持多种样式变体（默认、胶囊、按钮、线条）
  - 支持多种布局（顶部、底部、左侧、右侧）
  - 支持动态添加/删除标签
  - 支持禁用状态和懒加载

- **Toast 消息提示组件**
  - 支持4种类型（success、error、warning、info）
  - 支持6种位置（上下左右中）
  - 自动关闭和手动关闭
  - 鼠标悬停暂停、进度条显示
  - 全局 toast() 函数支持

#### 新增文件

- `static/js/components/dialog.js` - Dialog 组件
- `static/js/components/dropdown.js` - Dropdown 组件
- `static/js/components/tabs.js` - Tabs 组件
- `static/js/components/toast.js` - Toast 组件
- `static/css/components/dialog.css` - Dialog 样式
- `static/css/components/dropdown.css` - Dropdown 样式
- `static/css/components/tabs.css` - Tabs 样式
- `static/css/components/toast.css` - Toast 样式

## [3.0.0] - 2025-03-11

### 🎨 UI 升级 - shadcn-ui + Tabler 设计系统

#### 新增

- **shadcn-ui 组件库**
  - 引入 shadcn-ui 设计系统理念
  - 基于 Radix UI 的无头组件架构
  - 完全可定制的组件样式
  - 支持深色/浅色主题切换

- **Tabler Icons 图标库**
  - 集成 2000+ 专业开源图标
  - 统一的图标风格和尺寸
  - 支持图标字体和 SVG 两种格式

- **新组件**
  - `Button` - 多变体按钮组件（默认、主要、次要、幽灵、链接、危险）
  - `Card` - 卡片容器（支持头部、内容、底部区域）
  - `Badge` - 标签徽章（多种颜色变体）
  - `Table` - 数据表格（支持排序、筛选、分页）
  - `Dialog` - 模态对话框 | ✅ 已完成 (v3.1.0)
  - `Dropdown` - 下拉菜单 | ✅ 已完成 (v3.1.0)
  - `Tabs` - 标签页切换 | ✅ 已完成 (v3.1.0)
  - `Toast` - 消息提示 | ✅ 已完成 (v3.1.0)

- **主题系统升级**
  - 完整的 CSS 变量系统
  - 深色/浅色主题自动切换
  - 金融专用配色方案（红涨绿跌）
  - 自定义主题支持

- **文档**
  - 新增 [组件使用指南](./docs/COMPONENTS.md)
  - 新增 [主题定制指南](./docs/THEME.md)
  - 详细的代码示例和截图占位符

#### 变更

- **UI 框架**
  - 移除 Bootstrap 5 依赖
  - 迁移到自定义 CSS + shadcn-ui 设计系统
  - 重新设计所有页面组件

- **样式架构**
  - 采用 CSS 变量驱动的样式系统
  - 统一的间距、圆角、阴影规范
  - 响应式断点优化

- **图标系统**
  - 替换 Font Awesome 为 Tabler Icons
  - 统一图标尺寸和风格

#### 优化

- **性能**
  - CSS 文件体积减少 40%
  - 移除不必要的 JavaScript 依赖
  - 优化渲染性能

- **可访问性**
  - 提升键盘导航支持
  - 优化屏幕阅读器兼容性
  - 颜色对比度符合 WCAG 2.1 AA 标准

#### 设计参考

- [shadcn-ui](https://ui.shadcn.com/) - 现代 React 组件库设计规范
